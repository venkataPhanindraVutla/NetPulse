# NetPulse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS menu bar app that shows live ↓/↑ speed, per-app and per-network data usage (today/week/month), monthly history, and optional per-network caps with alerts. Local-only and open source.

**Architecture:** A Swift package, `NetPulseCore`, holds every piece of measurement and accounting logic: sysctl interface counters, a supervised `nettop -d` stream, process-to-app resolution, network identity, 15-minute UTC usage buckets in SQLite, and cap evaluation. All of it can be unit-tested with `swift test`. A thin SwiftUI app target (`MenuBarExtra`, `.window` style), generated by xcodegen, renders an `@MainActor @Observable` model fed by a `MonitorEngine` actor. A `netpulse-probe` CLI exercises the engine headless, used for the CPU gate and manual accuracy checks.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI + AppKit, Swift Charts, Swift Testing, system `libsqlite3`, SystemConfiguration, CoreWLAN, CoreLocation, UserNotifications, ServiceManagement, xcodegen. No third-party runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-28-netpulse-design.md`

## Global Constraints

- Minimum macOS **14.0**. Built on macOS 26.6 / Apple Silicon, Xcode 27.1, Swift 6.4, Swift language mode 6.
- **Not sandboxed**, hardened runtime on. No third-party runtime dependencies; SQLite is the system `libsqlite3`.
- **No outbound network calls** of the app's own. No telemetry, no update checker.
- Decimal units: 1 KB = 1,000 B, 1 MB = 10⁶ B, 1 GB = 10⁹ B. The rate setting switches MB/s ↔ Mbps (×8).
- Copy says **"device traffic"**, never ISP-billed usage. "Other / system" is always shown when > 0.
- Never store or display a negative delta. Never sum virtual interfaces (`lo*`, `utun*`, `bridge*`, `awdl*`, `llw*`, `ap*`, `anpi*`, `gif*`, `stf*`, `ipsec*`) into totals.
- Usage buckets: **15-minute UTC** buckets (`bucketStart = floor(unixSeconds / 900) * 900`). Aggregate in the user's *current* `TimeZone` at query time.
- Flush accumulated deltas to SQLite every **30 s** and on quit/sleep.
- Interface sampling **1 s**. `nettop` cadence **5 s** default, **15 s** floor. CPU budget **< 1% average** for NetPulse + `nettop` combined.
- Cap alerts at **80%** and **100%**, each at most once per cap period. Notification permission is requested only when the user first enables a cap. Location permission is requested once, at first run.
- Signing: owner's free Apple ID Personal Team. The team ID lives only in git-ignored `Config/Local.xcconfig`.
- MIT license. No AI attribution in README/source headers.

## Review Focus

1. **Mac sleeps or the wall clock jumps (NTP, manual change).** Speed must never spike or go negative; sleep must not credit hours of "missing" bytes in one tick. Speed uses the monotonic clock; wake resets baselines. Tests: Task 4 `wakeResetProducesNoDelta`, `speedUsesMonotonicElapsed`.
2. **Network switch mid-session (Wi-Fi → iPhone hotspot).** The first sample on the new interface is a baseline, and bytes before the switch stay with the old network. Test: Task 9 `switchAttributesToNetworkAtSampleTime`.
3. **CLI tools and daemons without an `.app` bundle (`curl`, `brew`, `git`, `softwareupdated`).** They must appear by process name, not vanish into Other. Test: Task 6 `bareExecutableUsesProcessName`.
4. **Travelling across timezones (IST → PST).** History re-buckets by the current timezone without losing or duplicating bytes. Test: Task 10 `totalsInvariantAcrossTimeZones`.
5. **`nettop` dies or stalls (killed, OS update changes output).** The app keeps showing speed and network totals, marks a gap, and backs off restarts instead of spinning. Tests: Task 7 `backoffSchedule`, `unparseableOutputCountsAsStall`.

  - `struct StoredNetwork: Sendable, Identifiable { let id: Int64; let key: NetworkKey; var displayName: String; var billingDay: Int }`
  - `struct AppUsage: Sendable, Identifiable { let id: String /* app key or "other" */; let displayName: String; let bundlePath: String?; let group: AppGroup?; let down: UInt64; let up: UInt64 }`
  - `struct Totals: Sendable, Equatable { var down: UInt64; var up: UInt64; var total: UInt64 { down + up } }`
  - `struct DayUsage: Sendable, Identifiable { let id: Date /* local day start */; let totals: Totals; let hasGap: Bool }`
  - `actor UsageStore { init(path: String) throws; func write(_ rows: [UsageRow]) throws; func recordGap(start: Date, end: Date, reason: String) throws; func networks() throws -> [StoredNetwork]; func updateNetwork(id: Int64, displayName: String, billingDay: Int) throws; func totals(network: Int64?, in: DateInterval) throws -> Totals; func appUsage(network: Int64?, in: DateInterval) throws -> [AppUsage]; func daily(network: Int64?, in: DateInterval, calendar: Calendar) throws -> [DayUsage]; func caps() throws -> [Cap]; func saveCap(_ c: Cap) throws }` (`Cap` from Task 11; add `caps`/`saveCap` in Task 11)

Schema (this replaces the spec's nullable `app_id`, because SQLite treats NULLs as distinct in a primary key):
```sql
CREATE TABLE networks(id INTEGER PRIMARY KEY, fingerprint TEXT UNIQUE NOT NULL, kind TEXT NOT NULL, display_name TEXT NOT NULL, billing_day INTEGER NOT NULL DEFAULT 1);
CREATE TABLE apps(id INTEGER PRIMARY KEY, key TEXT UNIQUE NOT NULL, bundle_id TEXT, display_name TEXT NOT NULL, bundle_path TEXT, grp TEXT NOT NULL);
INSERT INTO apps(id, key, display_name, grp) VALUES (0, '__total__', 'Total', 'system');
CREATE TABLE usage(bucket_start INTEGER NOT NULL, network_id INTEGER NOT NULL, app_id INTEGER NOT NULL, down INTEGER NOT NULL, up INTEGER NOT NULL, PRIMARY KEY(bucket_start, network_id, app_id)) WITHOUT ROWID;
CREATE TABLE gaps(start INTEGER NOT NULL, end INTEGER NOT NULL, reason TEXT NOT NULL);
CREATE TABLE caps(network_id INTEGER NOT NULL, period TEXT NOT NULL, limit_bytes INTEGER NOT NULL, enabled INTEGER NOT NULL, last_alert_period_start INTEGER, last_alert_threshold INTEGER, PRIMARY KEY(network_id, period));
PRAGMA user_version = 1; PRAGMA journal_mode = WAL;
```
`app_id = 0` is the network total. Writes: `INSERT … ON CONFLICT DO UPDATE SET down = down + excluded.down, up = up + excluded.up`, all in one transaction per `write`. A new network's `display_name` = `key.suggestedName`; an existing name is never overwritten. App metadata is refreshed on each write. The DB lives at `~/Library/Application Support/NetPulse/usage.sqlite`.

"Other": `appUsage` appends `AppUsage(id: "other", displayName: "Other / system", …)` = **per network** `max(0, total − Σapps)` per direction, summed over networks when `network == nil`. It is omitted when 0. Results are sorted by `down + up` descending, with Other always last.

### Task 12: MonitorEngine, probe CLI, CPU gate

**Files:**
- Create: `Sources/NetPulseCore/Engine/MonitorEngine.swift`, `Sources/netpulse-probe/main.swift`, `Tests/NetPulseCoreTests/MonitorEngineTests.swift`

**Interfaces:**
- Consumes: everything above.
- Produces:
  - `enum MonitorState: Sendable, Equatable { case monitoring, paused, degraded(String) }`
  - `struct EngineSnapshot: Sendable { let speed: Speed; let primaryNetwork: StoredNetwork?; let state: MonitorState; let appTrackingAvailable: Bool }`
  - `actor MonitorEngine { init(store: UsageStore, reader: any InterfaceCounterReading, detector: any NetworkDetecting, resolver: AppResolver, launcher: any LineProcessLaunching, nettopInterval: Int = 5); func start(); func pause(); func resume(); func willSleep(); func didWake(); func flush() async; func snapshots() -> AsyncStream<EngineSnapshot>; func setFastSampling(_ fast: Bool) }`

Behavior:
- Interface tick: every 1 s (5 s when `setFastSampling(false)`, i.e. the popover is closed **and** the label is icon-only). Each tick: read → `DeltaTracker` → `SpeedCalculator` (sum over physical deltas) → accumulator → snapshot. Discontinuities are logged, never stored as bytes.
- nettop: one `.external` supervisor by default. If ≥ 2 physical interfaces have non-zero deltas on **3 consecutive** ticks, swap to two supervisors (`.wifi`, `.wired`). Swap back after **60 s** with only one active. The swap itself records a gap.
- `.gap` events → `store.recordGap`; `appTrackingAvailable = false` while the supervisor is in backoff.
- Flush `accumulator.drain()` to the store every 30 s, plus on `willSleep`, `pause`, and `flush()`. `willSleep` also stops nettop. `didWake` resets `DeltaTracker` and `SpeedCalculator` and restarts nettop; the sleep span is recorded as a gap only if the app was monitoring.
- Pause: stop sampling and nettop; snapshots report `.paused` with `Speed.zero`.
